Chương 2: Cấu Trúc Điều Khiển & Vòng Lặp

1. Câu lệnh rẽ nhánh (if-else)

Dùng để thực thi các nhánh lệnh khác nhau dựa trên điều kiện logic.

if (diem >= 5.0) {
    cout << "Dau mon";
} else {
    cout << "Thi lai";
}

2. Vòng lặp (for, while)

Dùng để lặp lại các khối câu lệnh một số lần nhất định.

Danh sách Bài tập Chương 2

Bài 2.1: Tính giai thừa Trung bình

Nhập số nguyên dương $n$, tính và in ra giá trị $n!$.

Xem lời giải 
#include <iostream>
using namespace std;
int main() {
    int n;
    long long gt = 1;
    cin >> n;
    for(int i = 1; i <= n; i++) gt *= i;
    cout << "Giai thua = " << gt;
    return 0;
}

Bài 2.2: Kiểm tra số nguyên tố Khó

Nhập số nguyên $n$, kiểm tra xem $n$ có phải là số nguyên tố hay không.

Xem lời giải 
#include <iostream>
#include <cmath>
using namespace std;
int main() {
    int n;
    cin >> n;
    if (n < 2) { cout << "Khong phai SNT"; return 0; }
    bool nt = true;
    for(int i = 2; i <= sqrt(n); i++) {
        if(n % i == 0) { nt = false; break; }
    }
    if(nt) cout << n << " la so nguyen to";
    else cout << n << " khong phai so nguyen to";
    return 0;
}
