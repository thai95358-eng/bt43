1. Cấu trúc cơ bản của một chương trình C++

Mọi chương trình C++ đều bắt đầu thực thi từ hàm main():

#include <iostream>
using namespace std;

int main() {
    cout << "Chao mung den voi C++!" << endl;
    return 0;
}

2. Biến và Kiểu dữ liệu

C++ hỗ trợ các kiểu dữ liệu phổ biến: int, float, double, char, bool.

Danh sách Bài tập Chương 1

Bài 1.1: Tính tổng hai số nguyên Dễ

Viết chương trình nhập vào 2 số nguyên $a$ và $b$, in ra màn hình tổng của chúng.

Xem lời giải 
#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    cout << "Tong = " << a + b;
    return 0;
}
Làm bài thực hành này

Bài 1.2: Kiểm tra số chẵn lẻ Trung bình

Nhập vào một số nguyên $n$, kiểm tra xem $n$ là số chẵn hay số lẻ.

Xem lời giải 
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    if (n % 2 == 0) cout << n << " la so chan";
    else cout << n << " la so le";
    return 0;
}
